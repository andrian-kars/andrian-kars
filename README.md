Hi, I'm Andrian 👋 A senior full-stack engineer with 7+ years across enterprise insurance software and client applications. I build React/TypeScript interfaces and C#/ASP.NET Core services, and set up AI-agent workflows that help teams analyse, build, test and review, with people making the final call.

### What I do

- **AI-assisted engineering:** GitHub Copilot custom agents, reusable prompts and repository instructions that carry work from legacy analysis to review, with explicit handoffs, build and test checks, and human review gates.
- **Full-stack delivery:** legacy workflows modernized into React and TypeScript, backed by C#/ASP.NET Core APIs, permissions and data fixes.
- **Performance & architecture:** faster builds, fewer renders, shared component libraries and roadmaps teams can act on.
- **Team & delivery:** mentoring engineers from junior to senior, and automating the busywork around delivery.
